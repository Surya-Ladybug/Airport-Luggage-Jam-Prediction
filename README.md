# ✈️ Airport Luggage Jam Prediction

## Design for Industry 4.0 – Deliverable 3b

This project presents a machine learning–based Airport Luggage Jam Prediction system developed using Python and Streamlit.

The dashboard allows users to:

- View an overview of the project
- Perform dataset analysis
- Train the Random Forest prediction model
- Evaluate model performance
- View predictions on the test dataset

## Access the Application

Simply open the deployed Streamlit application using the link below.

**Streamlit App:**
[https://airport-luggage-jam-prediction.streamlit.app](https://airport-luggage-jam-prediction.streamlit.app)

No installation or setup is required. The application runs entirely in the browser.

## Repository Contents

- `app.py` – Streamlit dashboard
- `main.py` – Machine learning pipeline
- `src/` – Data preprocessing, model training, and evaluation
- `data/` – Dataset
- `images/` – Generated evaluation plots
