✈️ Airport Luggage Jam Prediction
Design for Industry 4.0 – Deliverable 3b

This project presents a Machine Learning-based Airport Luggage Jam Prediction System developed using Python and Streamlit. The application demonstrates predictive analytics and intelligent decision support for automated airport baggage handling systems in the context of Industry 4.0.

Features

The dashboard allows users to:

View an overview of the project
Perform dataset analysis
Train the Random Forest prediction model
Evaluate model performance
View predictions on the test dataset
🌐 Access the Application

The application is deployed on Streamlit Cloud and runs entirely in your web browser.

Streamlit App:
[https://airport-luggage-jam-prediction.streamlit.app](https://airport-luggage-jam-prediction-b9tc2tsrglhnkhqdyfsy9o.streamlit.app/)

No installation, dependency setup, or configuration is required. Everything has been integrated into the deployed application so it can be used directly from the browser.

📌 Getting Started

Please read this section before using the application.

The web interface has been designed as a scroll-based dashboard, so scrolling down is an important part of the user experience.

Steps to use the application
Open the Streamlit application.
Read the introductory project information displayed on the homepage.
Scroll down to reach the interactive dashboard.
From the left sidebar, select Dataset Analysis.
You will be prompted to upload the sample dataset.
Upload the provided sample dataset located in the repository:
data/
Once the dataset is uploaded, continue through the remaining workflow:
Dataset Analysis
Model Training
Model Evaluation
Prediction

The sample dataset has been included in this repository to make testing straightforward. This ensures the application runs exactly as intended without requiring users to generate their own data.
